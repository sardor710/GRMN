## Rulings

- **The public data cache is withdrawn, not shipped.** A cache that can serve an unpublished product or an old price after a takedown is worse than none, and every public page stays per-request with the new indexes. A correct cache needs:
  - a shared, bounded cache handler (for example Redis), or worker-driven invalidation fan-out to every instance (an infrastructure choice; Section 8 adds Redis only on measurement);
  - `revalidateTag(tag, { expire: 0 })`;
  - no caching of search, cursor or miss keys;
  - the rate version in the key;
  - invalidation at scheduled boundaries.

  21B's load run decides whether it is needed. **Cost if wrong:** without a cache, public reads hit the database every time, which is fine at the measured latencies.
- **Rate-limit identity is the trusted proxy address only.** Without a configured trusted proxy (development), the limits are skipped rather than collapsed into one global bucket. A shared office or carrier address shares one budget, with limits sized for that. **Cost if wrong:** a large office or a NAT could hit 30 checkouts/min; raise the limit, or add a per-account limit after authentication.
- **Browser E2E purchase lifecycles are blocked.**
  - Browser runs need ≥1 GB free RAM; this host had 0.1–0.4 GB.
  - A full purchase cannot reach "paid" in this build: the application registers only the simulated demo adapter (D03), and how staff confirm manual payment is owner decision **O07**, which is still open.
  - Guest, customer and staff lifecycles up to "awaiting payment", fulfilment and after-sales are covered at service level (14A–16B integration tests) and by the 14A browser smoke step.
- **Catalog and search plans are not measured.** They need a seed with categories, options, media and attributes. They are 21B work, together with the load runs.
- **Chain stop.** The remaining 21A items and all of 21B need a shared cache handler (an infrastructure decision), VPS-class hardware (O05), more RAM than this host has, and a payment confirmation path (O07). Those are owner or infrastructure decisions, so the chain stops instead of producing evidence that would not support the capacity envelope.
